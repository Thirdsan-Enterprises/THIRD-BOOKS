Usage Guidelines

✅ Do's

• Use primary (indigo) for main actions and interactive elements
• Use secondary (green) for positive financial metrics and success states
• Use accent (amber) sparingly for warnings and attention items
• Maintain consistent spacing using multiples of 4px
• Ensure proper color contrast for accessibility (WCAG AA)

❌ Don'ts

• Don't mix too many colors in a single view
• Don't use pure black (#000) - use gray-900 instead
• Don't rely on color alone to convey meaning
• Don't forget focus states for accessibility
• Don't create new spacing values outside the system
